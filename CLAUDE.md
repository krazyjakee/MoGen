# CLAUDE.md

**MoGen** (`mogen`): Rust CLI compiling a declarative DSL (`.mog`) into glTF 2.0 `.glb`, the
deterministic backend of an LLM-driven 3D pipeline. Target engine Godot 4.x; output must stay
spec-compliant. Desktop GUI: **MoGen Studio** (`mogen-studio`).

## Commands

```sh
./scripts/build-release.sh              # cargo build --release --workspace
./scripts/run-tests.sh                  # cargo test --workspace
./scripts/run-mogen.sh <subcommand> …   # CLI (see docs/cli.md)
./scripts/run-studio.sh                 # Studio
cargo test -p mogen-dsl                 # one crate
MOGEN_GOLDENS_UPDATE=1 cargo test -p mogen --test goldens   # regenerate GLB goldens
```

## Architecture

Pipeline (keep crate deps one-directional):
`mogen-dsl` parse → AST → `mogen-validate::validate_ast` → lower → `mogen-core::SceneGraph`
→ `validate_graph` → `mogen-export` → `.glb`.

- **mogen-core** — pure data (SceneGraph, Transform, Mesh, Material, Connector, animation, Skin,
  Diagnostic). No I/O.
- **mogen-dsl** — pest grammar, AST, lowering (`lower/`), modules, attach, anim/skin lowering.
- **mogen-validate** — AST pass (spans) and graph pass; human + JSON diagnostic renderers.
- **mogen-geom** — primitives, CSG via `manifold-csg`, mesh cleanup. Features: `csg` (default,
  native) vs `unstable-wasm-uu` (for `mogen-wasm`, needs LLVM 20+) — mutually exclusive.
- **mogen-anim** — procedural clip templates. **mogen-export** — GLB/FBX writer, mesh merge,
  SVG pre-pass. **mogen-svg** — SVG → PNG. **mogen-render** — glow PBR renderer/thumbnails.
- **mogen-llm** — LLM providers, prompt assembly, bounded repair loop, texture generation.
- **mogen-pascal** — pascalorg/editor JSON importer. **mogen-import** — mesh importer (glTF/GLB
  → mesh IR → `poly` source; ingest → normalize → convert passes → emit; emits text only).
- **mogen-registry** / **mogen-moghub-client** — `use "@user/slug"` resolution and MoGHub client
  (web repo lives at `../moghub`).
- **mogen-binary** — experimental MOGB container. **mogen-update** — self-updater.
- **mogen** — CLI binary. **mogen-studio** — eframe/egui app reusing the CLI pipeline.
  **mogen-wasm** + `web/` — browser preview.

## Invariants

- **Determinism.** Same source + seed ⇒ byte-identical output. No HashMap iteration order,
  wall-clock, or thread races in lowering/generators/export.
- **Procedural generators** (`branch`, `building`, `cave`, `terrain`, `dungeon` in
  `mogen-dsl/src/lower/`): seed via `lower/rng.rs` with `mix_seed` sub-streams per phase; wrap
  in `begin_procedural()`/`finish_procedural()` (subtree stamped `editable=false`); declare
  params in `proc_schema.rs` (Studio renders UI from it — no per-kind Studio code); emit POIs
  via `lower/poi.rs` (LOD-invariant); use shared `cfg.rs`/`lod.rs`/material-default helpers.
- **Architectural IR** (`lower/arch/`): producers (pascal importer, `building`) only map
  fields; all geometry maths lives in `arch/`. No RNG; output shapes are closed solids;
  junctions covered exactly once; openings emit `use "door_simple"`/`"window_simple"`; roofs
  are lifted onto supporting walls. `building/tests/parity.rs` guards parity.
- Validation stays dual: referential/typing on AST, geometric/topological on SceneGraph. AST
  nodes keep pest spans.
- Modules are grammar productions with lexical `$param` scope — never string substitution.
- Connectors are oriented frames (pos + quat + tag); never reduce to position-only.
- Animation v1 = node-transform tracks; skinning is separate and additive.
- glTF coords: right-handed, +Y up, −Z forward. Math uses `glam`.
- `examples/buildings/gatehouse.pascal.json` is generated by
  `crates/mogen-pascal/tests/fixtures/make_gatehouse.py` (edit the script) and must never
  import cleanly.

## Conventions

- Branding: **MoGen** / **MoGen Studio** in prose/UI; lowercase for crates, binaries, env vars.
- Studio: never `.small()` on user-facing text; use `.weak()` for de-emphasis. `.small()` only
  on glyph-only buttons.
- Env vars: `MOGEN_CACHE_DIR` (default `$HOME/.cache/mogen/`), `MOGEN_GOLDENS_UPDATE`,
  `MOGEN_GLTF_VALIDATOR`.
- Docs: `docs/dsl.md` (language), `docs/modules.md` (stdlib), `docs/cli.md`, `docs/studio.md`.
  These are embedded in Studio (`mogen-studio/src/docs.rs` links heading slugs — keep them
  in sync). Read only the section you need.
